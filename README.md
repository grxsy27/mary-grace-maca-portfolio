# Mary Grace Maca Portfolio

React + Vite single-page portfolio with smooth-scroll navigation.

## Sections
- Home
- Works
- Resume
- Contact
- Footer: “2026, All Rights Reserved to Mary Grace Maca”

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local Vite URL shown in the terminal.

## Customize
- Edit project content in `src/main.jsx`.
- Edit visual styling in `src/styles.css`.
- Replace the placeholder email in `src/main.jsx`.
- Put your actual `resume.pdf` in the project root if you want the Download Resume button to work.
